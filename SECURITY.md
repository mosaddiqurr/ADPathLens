# Security policy

ADPathLens is a defensive, local-first analysis tool. Report suspected vulnerabilities privately
to the repository owner. Do not attach real directory exports, credentials, session cookies,
secrets, or other operational evidence to a public report.

Use the latest reviewed source revision. No hosted service or release support guarantee is implied.

Security boundaries, authorized-use requirements, deployment hardening, and residual risks are
documented in [docs/SECURITY.md](docs/SECURITY.md),
[docs/THREAT_MODEL.md](docs/THREAT_MODEL.md), and
[docs/AUTHORIZED_USE.md](docs/AUTHORIZED_USE.md).
