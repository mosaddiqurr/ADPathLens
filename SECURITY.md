# Security policy

ADPathLens is a defensive analysis tool. Report suspected vulnerabilities privately to the
repository owner; do not include real directory exports, credentials, session cookies, or secrets.

Supported release candidate: `adpathlens-v1.0.0-rc1`.

Security boundaries and operational requirements are documented in
[docs/SECURITY.md](docs/SECURITY.md) and [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md).
